# Placeholder Assets

The first development placeholders are included under
`assets/images/placeholders/` for Character, Battle, Adventure, and Job.

Placeholder types and their expected paths are defined in
`docs/assets/image-guidelines.md`. Create the actual files when they become
necessary during implementation.

Placeholder assets are temporary development assets and must not be used as
final game assets. They are original repository-created SVGs with no
third-party source.
